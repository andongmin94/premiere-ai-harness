# 제거 및 데이터 초기화

## 플러그인 안에서 초기화

패널의 `플러그인 데이터 초기화` 버튼은 다음을 삭제합니다.

- 호스트 자체시험 인증
- 플러그인의 localStorage 설정
- 현재 패널 세션의 분석 상태

다음은 삭제하지 않습니다.

- 사용자가 만든 러프컷 시퀀스
- `PAI_OUTPUT_` 빈과 해당 서브클립
- 원본 미디어와 기존 시퀀스

이 항목들은 Premiere 프로젝트의 사용자 결과물이므로 플러그인이 임의로 제거하지 않습니다.

`시험 흔적 정리` 버튼은 `PAI_INTERNAL_SELFTEST_` 또는 `PAI_INTERNAL_TEMP_` 이름을 가진 내부 시험 자산만 제거합니다.

## 플러그인 제거

Creative Cloud Desktop의 플러그인 관리에서 Premiere AI Harness를 제거합니다. UXP 플러그인의 데이터 폴더는 제거 시 삭제 대상이며, 이미 프로젝트에 만든 시퀀스와 프로젝트 아이템은 프로젝트 파일 안에 유지됩니다.

## 완전한 프로젝트 정리

완성된 러프컷까지 없애려는 경우 Premiere 프로젝트에서 해당 러프컷 시퀀스와 연결된 `PAI_OUTPUT_` 빈을 사용자가 직접 확인한 뒤 삭제하십시오. 이 작업은 되돌릴 수 있으므로 프로젝트 백업 후 수행하는 것이 안전합니다.
