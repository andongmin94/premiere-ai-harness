# 제거 및 데이터 초기화

## 플러그인 안에서 초기화

패널의 `플러그인 데이터 초기화` 버튼은 다음 플러그인 소유 데이터만 삭제합니다.

- 호스트 자체시험 인증
- Core 0.5.1 실제 Premiere 검증 기록
- 현재 패널 세션의 선택 원본·전사문·편집안 상태

다음은 삭제하지 않습니다.

- 사용자가 만든 러프컷 시퀀스
- `PAI_OUTPUT_` 빈과 해당 서브클립
- 원본 미디어와 기존 시퀀스
- 다른 플러그인이나 호스트가 사용하는 localStorage 항목

`시험 흔적 정리` 버튼은 엄격한 내부 이름과 이번 플러그인 소유 조건을 만족하는 자체시험 자산만 제거합니다. 사용자가 만든 출력이나 이름이 비슷할 뿐인 항목은 제거하지 않습니다.

## 검증 기록만 초기화

`실제 Premiere 검증` 영역의 `검증 기록 초기화`는 호스트 인증과 편집 세션은 유지하고, 단계별 검증 기록만 삭제합니다.

## 플러그인 제거

Creative Cloud Desktop의 플러그인 관리에서 Premiere AI Harness를 제거합니다. UXP 플러그인의 저장 데이터는 제거 대상이지만, 이미 프로젝트에 만든 시퀀스와 프로젝트 아이템은 Premiere 프로젝트 파일 안에 유지됩니다.

## 완전한 프로젝트 정리

완성된 러프컷까지 없애려는 경우 Premiere 프로젝트에서 해당 러프컷 시퀀스와 연결된 `PAI_OUTPUT_` 빈을 사용자가 직접 확인한 뒤 삭제하십시오. 플러그인은 사용자 결과물을 자동 제거하지 않습니다.
