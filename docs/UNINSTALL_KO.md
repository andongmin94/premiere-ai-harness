# 제거 및 데이터 정리 — Core 0.3.1

패널의 `플러그인 데이터 초기화`는 다음만 삭제합니다.

- `pai.core.host-certification.v1` 호스트 인증 키
- 현재 패널 세션의 선택·전사·편집안 상태

다른 localStorage 키, 원본, 기존 시퀀스, 사용자가 만든 러프컷은 삭제하지 않습니다.

`시험 흔적 정리`는 엄격한 내부 시험 이름 규칙에 맞는 시퀀스와 빈만 대상으로 하며, 내부 빈에 예상하지 못한 사용자 항목이 있으면 삭제하지 않고 오류를 표시합니다.

플러그인 제거는 공식 CCX를 만든 뒤 Creative Cloud Desktop의 플러그인 관리에서 수행합니다. 현재 `dist/*-uxp-source`는 개발용 source directory이므로 설치 프로그램이 아닙니다.
